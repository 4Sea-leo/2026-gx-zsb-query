# 2026年广西专升本招生计划查询系统

在线查询广西2026年普通高等教育专升本招生计划，支持多维度筛选、录取概率计算和智能填报推荐。

## 功能

- **详细计划表**：1062条招生数据，按梯队/院校/大类/文理/考生类型筛选，支持关键词搜索
- **学校总览**：36所院校招生概览，按梯队分组
- **考试科目**：19个专业大类考试科目一览
- **医药卫生**：专科→本科专业对应查询
- **智能填报**：平行志愿大类排名概率模型，一键推荐可报专业
- **录取概率**：基于累计招生数的冲-稳-保分析

## 数据来源

广西招生考试院《2026年普通高等教育专升本招生计划》

## 使用方法

直接用浏览器打开 `2026广西专升本招生计划查询.html`，无需任何依赖。

## 算法说明

采用**平行志愿大类排名模型**：
- 每个专业大类独立排名，竞争仅在大类内进行
- 累计招生数 > 排名 → 必录区间（保底/稳妥）
- 累计招生数 ≤ 排名 → 冲刺区间
- 医药卫生大类独立加权，基于专科→本科映射计算竞争比
